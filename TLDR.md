## 🚀 THE COMMANDS

### Pick One & Run:

```bash
npm run create              ← RECOMMENDED (any OS)
```

or Windows:
```bash
create-video.bat            ← Windows CMD/PowerShell
```

or PowerShell:
```powershell
.\create-video.ps1
```

or macOS/Linux:
```bash
./create-video.sh
```

or Python:
```bash
python create_video.py
```

---

## 🎯 THAT'S IT!

Runs automatically:
1. ✅ Fetches latest news (1 min)
2. ✅ Generates script (1-2 min)
3. ✅ Creates video guide (30 sec)

**Result: Video script ready in ~2-3 minutes!**

---

## 📁 OUTPUT

Check these folders:
- `videos/YYYY-MM-DD/` → Markdown content
- `videos_scripts/` → Video scripts (JSON + TXT)
- `generated_videos/` → Resources
